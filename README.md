# Phantom CS2 CFG

Готовый персональный конфиг CS2 для AORUS 16X 9KG (i7-13650HX / RTX 4060 Laptop / 16 GB RAM).

Цель: стабильные **120 FPS**, более спокойная картинка при спрее, сохранённые sensitivity/прицел/бинды и максимально убранный в правый нижний угол viewmodel.

## Установка

1. Скачать `Phantom.cfg`.
2. Положить файл сюда:

`D:\SteamLibrary\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\Phantom.cfg`

3. Steam → Counter-Strike 2 → Properties → Launch Options:

`+exec Phantom.cfg`

## Основное

- `fps_max 120`
- `fps_max_ui 120`
- `cl_crosshair_recoil 0`
- `r_drawtracers_firstperson 0`
- `r_fullscreen_gamma 2.4`
- `viewmodel_fov 68`
- `viewmodel_offset_x 2.5`
- `viewmodel_offset_y 2`
- `viewmodel_offset_z -2`

Для работы `r_fullscreen_gamma 2.4` лучше использовать режим **Fullscreen**.
